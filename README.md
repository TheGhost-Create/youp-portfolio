## Présentation du Projet

Ce projet est le portfolio professionnel haut de gamme conçu et développé pour **YOUP-YOUP SOTER AUTON**.
Il s'agit d'un produit numérique immersif répondant à la direction artistique **DARK FUTURISTIC × CREATIVE EDITORIAL**, combinant ses quatre grands domaines de compétence :

1. **Développement Informatique & Web** : React, Vite, JavaScript moderne, Python, architectures modulaires.
2. **Cybersécurité & Administration Linux** : Kali Linux, Debian, surveillance de processus (`psutil`), analyse de sockets TCP/IP et moteur d'alertes.
3. **Design Graphique** : Adobe Photoshop, compositions publicitaires haute fidélité (ex: affiche officielle *Keyce Informatique 2024/2025* 1080×1080 px, flyer *Digitara Academy*).
4. **Motion Design & Expériences 3D** : Three.js temps réel avec sculpture métallique cinétique réactive au curseur, Unity 3D URP, typographie cinétique.

## Démarrage Local

Sous Windows avec Visual Studio Code et PowerShell :

### 1. Installation des dépendances (déjà effectuée)
```powershell
npm.cmd install
```

### 2. Démarrer le serveur de développement
```powershell
npm.cmd run dev
```
Le serveur local démarre sur `http://localhost:5173`.

### 3. Tester la compilation de production
```powershell
npm.cmd run build
```
